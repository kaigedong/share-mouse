# 实现方式1:

通过websocket传递数据, 首先在一个服务器开启服务，在另一个服务器开启客户端服务。

所有客户端启动端口连接,可以做一个类似Syncthing的监听页面

1. 所有程序启动后，进行端口监听，也就是能够方便的连上其他设备

2. 在有鼠标的电脑上，点击添加设备，输入另一个启动的电脑的ID 和 KEY 即可不需要另一个电脑确认，就能添加另一个电脑设备

主控端使用被控端的公钥加密，被控端进行解密鼠标和键盘的行为

(这时候被控制的电脑通过自己的key)

3. 控制被控端之后，需要有快捷键能退出控制。

4. 拓展屏幕模式：可以按一定方式排列屏幕，当鼠标进入屏幕边缘时，可以自动进入下一个屏幕

   - 例如有一个电脑，有一个平板，应该能让鼠标丝滑的从电脑移动到平板

5. 需要所有设备都能使用,也就是GUI不是必须的。

6. 需要有代理模式，也就是能通过某个代理，控制更远的设备

7. 未来不止鼠标键盘，还能添加手柄设备()

8. 需要能有WEB界面,这样没有屏幕的设备也能安装运行(为了界面美观和统一，感觉这个是最不必须的)
